# 💰 Expense Tracker

A modern **MERN Stack** web application that helps users track their income and expenses, monitor their financial balance, and organize transactions with an intuitive and responsive interface.

---

## ✨ Features

- ➕ Add income and expense transactions
- 🗑️ Delete transactions
- 📊 View total income, expenses, and current balance
- 🏷️ Categorize transactions
- 💾 Store data securely in MongoDB
- 📱 Responsive and user-friendly design

---

## 🚀 How to Run

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/expense-tracker.git
cd expense-tracker
```

### 2️⃣ Install dependencies

Backend

```bash
cd server
npm install
```

Frontend

```bash
cd ../client
npm install
```

### 3️⃣ Configure environment variables

Create a `.env` file inside the **server** folder.

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

### 4️⃣ Start the application

Backend

```bash
cd server
npm run dev
```

Frontend

```bash
cd client
npm run dev
```

Open **http://localhost:5173** in your browser.
